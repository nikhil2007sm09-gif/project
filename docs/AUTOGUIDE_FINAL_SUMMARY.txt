CUSTOMIZATION
================================================================================

Change Colors:
   Edit AutoGuide.css
   .guide-highlight { border: 3px solid #your-color; }
   .guide-btn-next { background: #your-color; }

Change Position:
   position: 'top' // 'top', 'bottom', 'left', 'right'

Disable Highlight:
   highlight: false

Add New Guide:
   1. Edit AutoGuide.jsx
   2. Add to guides object
   3. Include in page: <AutoGuide page="myPage" />

================================================================================
TROUBLESHOOTING
================================================================================

Guide not showing?
   localStorage.removeItem('seenGuides')
   location.reload()

Highlight in wrong position?
   - Check CSS selector in AutoGuide.jsx
   - Verify element class exists

Tooltip going outside?
   - Change position: 'top', 'bottom', 'left', 'right'
