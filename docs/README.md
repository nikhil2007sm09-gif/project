## 📊 Project Features

**Pura Project** includes:

- ✅ Multi-role authentication (Customer, Admin, Affiliate)
- ✅ Product management with categories, sizes, colors
- ✅ Shopping cart & checkout system
- ✅ Razorpay payment integration
- ✅ Affiliate system with commission tracking
- ✅ Admin dashboard with analytics
- ✅ Blog system
- ✅ Contact form
- ✅ Email & SMS notifications
- ✅ Responsive design
- ✅ Archive system for data management
