# 🚀 Website Startup Guide

## Quick Start Commands

### 1. Start Backend Server
```bash
cd backend
npm install
npm run seed
npm run dev
```

### 2. Start Frontend (in new terminal)
```bash
cd frontend
npm install
npm run dev
```

## 🔧 Troubleshooting

If you still see errors:

1. **Clear browser cache** - Press Ctrl+Shift+R (or Cmd+Shift+R on Mac)
2. **Restart dev server** - Stop with Ctrl+C and run `npm run dev` again
3. **Check console** - Look for any remaining errors in browser console
